來源及使用許可見根目錄 CREDITS.md。原始 PNG 保持不變。

原始影格為 64×64；裁切座標相對於每格。角色以原始像素密度繪製，
腳底基準為小鎮 32×32 格內的 y=28，保留動作本身的上下起伏。
牛、鵝原圖朝右；兔子、企鵝、青蛙朝左，行走時依方向水平翻轉。
只左右漫步，沿用地圖阻擋檢查與等級走動機率。
兔子四個走路影格的位移倍率為 0、0.75、2.25、1，平均速度 16px/s。
企鵝與鵝速度 14px/s，牛為 12px/s。鵝的裁切視窗向右移 2px，完整保留拍翅影格。
青蛙的跳躍由八個時間格組成（10 FPS、0.8 秒一跳），共用四張原始圖檔。
離地高度為 0、3、6、7、6、3、0、0px；水平位移倍率為 0、1、2、2、2、1、0、0，
平均速度 16px/s。到達目的地後完成落地才切回待機。
Idle.png 的第二列重複第一列的鼓喉影格，因此只播放第一列兩個不同姿勢。
每種動物的描繪由地圖、面板及預覽共用。

驗證：`node tools/test-animals.js` 檢查行為與繪製合約；
`node tools/test-appearance-model.js` 檢查儲存格式；
`node tools/test-appearance-browser.js` 檢查瀏覽器互動（需 Playwright，詳見該檔）。
