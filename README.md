# 貓咪小鎮

早安。這是一個專門為教室大螢幕投影設計的課堂激勵工具。全班每位學生都會化身為草地地圖上的一隻貓咪，頭上標示著座號（或姓名）與進度條。當你在課堂上給予獎勵時，貓咪會累積經驗值並當場升級。

這個系統完全在你的電腦上離線運作。不需要註冊帳號，沒有任何網路連線，也沒有學生登入介面。只有你可以操作它。

## 60 秒快速上手（如何在今天的第一堂課使用）

如果你待會就要上課，請按照以下步驟操作：

1. **啟動系統**：雙擊資料夾裡的 `啟動.bat`。它會打開一個黑色的視窗，然後自動在瀏覽器中開啟小鎮畫面。
2. **連接資料夾**：點擊畫面上方的「連接資料夾」按鈕，選擇本專案內的 `data` 資料夾（是選擇這個資料夾本身，不要點進去選檔案），接著 Chrome 會再問一次要不要讓這個網站編輯檔案，按「編輯檔案」（有些版本寫「儲存變更」）。
3. **給予獎勵**：點擊任何一隻貓咪，右側會滑出角色面板。按下大大的 `＋1` 按鈕（或按鍵盤的 `Enter` / `空白鍵`），就可以為該學生加分，貓咪會有動畫反應。
   點一下貓只會打開面板，不會改到分數；真正加分一定要在面板上再按一次，所以上課時不小心點到不會有事。
4. **結束與存檔**：加完分後可按 `Esc` 關閉面板。下課時，直接關閉那個黑色的啟動視窗，系統就會停止。分數都會自動存檔。

## 準備工作：匯入學生名單

如果你還沒匯入真實的學生姓名，只要你完成上述的「連接資料夾」步驟，系統就會在找不到 `data/class-data.json` 時自動產生一份預設名單，上面只會有座號與零分，方便你今天先試用。

之後有空時，你可以這樣匯入真實名單：

1. 將學生名單存入 `tools/names.txt` 檔案中。
2. 在命令列執行 `python tools/import_roster.py`。
3. 詳細的匯入細節請參考 `AGENT-名單匯入.md`。

## 詳細操作參考

### 啟動與瀏覽器限制

- 執行 `啟動.bat` 會啟動一個小型的本機網頁伺服器，並自動開啟瀏覽器。預設會使用 8173 連接埠，如果被其他程式佔用，它會自動往上尋找可用的埠（最高到 8200）。
- **必須使用 Chrome 或 Edge。** 這個工具需要寫入檔案，而寫入功能（File System Access API）在 Firefox 與 Safari 中不存在。如果偵測到不支援的瀏覽器，畫面會直接提示你。
- 若要關閉系統，只需關閉一開始彈出的黑色命令列視窗即可。

### 連接資料夾的機制

這通常是大家最容易卡住的步驟。基於瀏覽器的安全規則，網頁絕對不能任意觸碰你的硬碟，除非你親自「遞」一個資料夾給它。這是一項嚴格的瀏覽器限制，而不是設計上的選擇。

- 在你選擇 `data` 資料夾並授權之前，系統是唯讀的：貓咪會動，但任何分數都不會儲存。
- 這個授權會被瀏覽器記住。在之後的課堂中，你通常只需要再點擊一次確認即可。
- 連接成功後，工具列上的「連接資料夾」會換成**班級下拉選單**，旁邊的小圓燈亮綠色代表可以正常存檔。

### 帶多個班級

程式會自動掃描 `data` 資料夾裡所有的 `.json` 檔（`class-data.example.json` 不算），每一個檔案就是一個班級，全部列在工具列的下拉選單裡。上課前從選單挑那一班就好，切換時會自動把還沒寫完的分數先存起來。

要新增一個班級，就在 `data` 資料夾裡放一個新的 `.json`（用 `tools/import_roster.py --class-id 新班級代碼` 產生最省事），重新整理網頁就會出現在選單裡。

### 分數與等級的換算

- 每位學生一學期的滿分是 30 分，每得 3 分會升 1 級，最高 10 級。
- 這個「等級」數字，就是學期末你可以直接填入平時成績的加分（例如：7 級代表加 7 分）。
- 當學生達到 30 分滿分時，面板上的按鈕會變成灰色，並停止記錄新的分數。
- 請注意，檔案中永遠只會儲存「分數」，等級都是由程式即時推算出來的，不會另外儲存。

### 復原操作 (Undo)

上課節奏很快，按錯是難免的，系統為此準備了完整的復原機制：

- 復原只在角色面板裡操作：點開那隻貓，面板下方每一筆紀錄旁邊都有「復原」按鈕。面板開著時也可以按 `Ctrl+Z` 復原最後一次加分。
- 復原的運作方式是「在歷史紀錄中加上一筆退回的紀錄，並將原本那筆標記為撤銷」。**系統永遠不會從紀錄中刪除任何東西**。當學生對分數有疑慮時，這些紀錄是你唯一的依據。
- 復原後，畫面會短暫出現訊息，並提供「取消復原」的選項讓你反悔。
- 復原功能跨越課堂依然有效。即使是昨天的操作失誤，今天依然可以復原。
- 這是系統內**唯一**可以扣除分數的方式，這是刻意設計的。

### 存檔與備份

- 加分後，系統會等待約 1 秒鐘再寫入檔案，因此連續快速加分只會觸發一次存檔。
- 每天第一次存檔時，系統會把**寫入之前**的檔案內容複製一份到 `data/backups/`，保留最近 30 份（份數由 `CONFIG.BACKUP_KEEP_DAYS` 決定）。備份的是舊內容而不是新內容，這樣今天誤操作才救得回昨天的狀態。
- **資料保護**：如果 `class-data.json` 檔案被改壞、無法順利解析，系統會顯示紅色橫幅，並拒絕寫入任何資料。這樣可以避免覆蓋掉原本的檔案而造成資料永久損壞。請在文字編輯器中修正該檔案後，點擊工具列的 ↻ 按鈕。

## 自訂設定 (config.js)

你可以用文字編輯器打開 `js/config.js`，修改裡面的設定。只要是合法的修改，存檔後重新整理網頁就會生效。幾個較常變動的項目包含：

- `TITLE`：顯示在畫面上方的文字。
- `CLASS_ID`：預設先開哪一個班級。連上資料夾後可以直接用工具列的下拉選單切換，通常不需要改這裡。
- `PLACEHOLDER_STUDENT_COUNT`：無名單時的佔位學生人數。
- `XP_MAX`、`XP_PER_LEVEL`、`MAX_LEVEL`：調整滿分與升級的門檻。
- `AWARD_VALUES`：設定加分按鈕的數值（若需要多種加分按鈕可以新增）。
- `LEVEL_TITLES`：每個等級的稱號名稱。
- `SHOW_XP_NUMBERS`：是否在進度條旁顯示確切的分數。
- `MAP_COLS`、`MAP_ROWS`：地圖的寬與高。**強烈建議：** 調大 `MAP_ROWS` 可能會導致畫面為了適應螢幕，將放大倍率從 2x 降回 1x。這會讓投影在黑板上的文字變得極小而難以閱讀。改完可以在瀏覽器主控台確認 `S.scale`，只要不是 2 就代表地圖太大了。
- `MAP_SEED`：改變此數字可重新隨機生成一張全新的地圖。
- `MIN_SPACING`：貓咪之間的最小間隔。
- `WANDER_RADIUS`：貓咪在原地的活動範圍。
- `BACKUP_KEEP_DAYS`：自動備份保留天數。

## 命令列工具

專案內的 `tools/` 資料夾提供了一些指令工具（需在命令列執行）：

- `python tools/import_roster.py`：將純文字名單轉為 JSON 資料檔（參見 `AGENT-名單匯入.md`）。
- `python tools/export_grades.py`：匯出 `data/export-YYYY-MM-DD.csv` 供期末結算成績。
- `node tools/test-model.js`：測試分數與等級計算邏輯是否正常。
- `tools/spritesheet-viewer.html`：用於在瀏覽器中重新確認角色素材的格線座標（若日後更換圖片素材會用到）。

## 刻意省略的功能

為了符合真實的教室情境，這套系統刻意排除了以下功能，並非遺漏：

- **沒有排行榜或排名機制**。
- **除了復原之外，沒有減分功能**。
- **沒有死亡、昏倒或出局的視覺表現**。貓咪的姿勢只反映正向的差異：等級低的貓是坐著理毛，等級高的會站起來走動、腳邊冒小星星，滿級戴上金色光環。整套動畫裡不會出現趴著或睡覺，分數低的學生不會在全班面前看起來沒精神。
- **進度條絕對不使用紅色**。
- **沒有任何音效**。
- **沒有學生登入介面，也沒有網路連線**。分數只存在於你這台電腦的檔案裡。

## 疑難排解

| 狀況 | 說明與解決方法 |
| :--- | :--- |
| **雙擊 `啟動.bat` 卻一閃而過，無法開啟** | 電腦可能未安裝 Python。請至 Python 官網下載安裝，安裝時務必勾選「Add Python to PATH」選項，重新開機後再試。 |
| **點擊「連接資料夾」毫無反應** | 現在不會再毫無反應了 —— 一定會跳出訊息說明原因，請照著上面寫的做。若訊息說「被取消，或是根本沒有開起來」，先看一下工作列，選擇視窗有可能開在 Chrome 後面或另一個螢幕。啟動時的黑色視窗會顯示「瀏覽器：chrome.exe」或「msedge.exe」，可以確認用的是哪一個。 |
| **貓咪頭上只顯示數字，沒有姓名** | 這是還沒匯入真實名單時的正常狀態，顯示的是座號。匯入名單後就會變成姓名。 |
| **畫面上方出現紅色橫幅警告檔案損毀** | 系統發現你的 `class-data.json` 檔案格式有誤（通常是因為手動編輯時漏了括號或逗號）。系統已切換為唯讀以保護資料。請用文字編輯器將檔案修復，再點擊工具列的 ↻ 按鈕。 |
| **手動編輯 JSON 後，分數看起來不對勁** | 系統的歷史紀錄與總分是連動的，手動編輯如果沒有同步處理可能會出現異常。強烈建議不要手動去改檔案裡的數字，請使用介面上的復原功能，或是透過 `tools/import_roster.py` 來維護名單。 |
