# 貓咪小鎮

早安。這是一個專門為教室大螢幕投影設計的課堂激勵工具。全班每位學生都會化身為草地地圖上的一隻貓咪，頭上標示著座號與姓名、以及進度條。當你在課堂上給予獎勵時，貓咪會累積經驗值並當場升級。

這個系統完全在你的電腦上離線運作。不需要註冊帳號，沒有任何網路連線，也沒有學生登入介面。只有你可以操作它。

## 60 秒快速上手（如何在今天的第一堂課使用）

如果你待會就要上課，請按照以下步驟操作：

1. **啟動系統**：雙擊資料夾裡的 `啟動.bat`。它會打開一個黑色的視窗，然後自動在瀏覽器中開啟小鎮畫面。
2. **連接資料夾**：點擊畫面上方的「連接資料夾」按鈕，選擇本專案內的 `data` 資料夾（是選擇這個資料夾本身，不要點進去選檔案），接著 Chrome 會再問一次要不要讓這個網站編輯檔案，按「編輯檔案」（有些版本寫「儲存變更」）。
3. **給予獎勵**：點擊任何一隻貓咪，右側會滑出角色面板。按下大大的 `＋1` 按鈕（或按鍵盤的 `Enter` / `空白鍵`），就可以為該學生加分，貓咪會有動畫反應。
   點一下貓只會打開面板，不會改到分數；真正加分一定要在面板上再按一次，所以上課時不小心點到不會有事。
4. **結束與存檔**：加完分後可按 `Esc` 關閉面板。下課時，直接關閉那個黑色的啟動視窗，系統就會停止。分數都會自動存檔。

## 準備工作：匯入學生名單

如果你還沒匯入真實的學生姓名，只要你完成上述的「連接資料夾」步驟，系統就會在找不到 `data/class-data.json` 時自動產生一份預設名單，上面只會有座號與零分，方便你今天先試用。

之後有空時，你可以這樣匯入真實名單：

1. 將學生名單存入 `tools/names.txt` 檔案中。
2. 在命令列執行 `python tools/import_roster.py`。
3. 詳細的匯入細節請參考 `AGENT-名單匯入.md`。

## 詳細操作參考

### 自訂學生形象

點擊學生角色，在右側面板底部按「編輯形象」，即可選擇貓咪、兔子、企鵝、牛、鵝或青蛙。
貓咪可選灰、橘、白三種毛色，以及配件；其他動物直接使用完整動物形象。
預覽下方可切換待機、走路、加分動作，按「套用形象」後更新小鎮並自動存檔。
按「取消」或 `Esc` 關閉預覽。

先連接 `data` 資料夾才能套用形象；尚未連接時可以預覽。
外觀隨每位學生的資料儲存，重新載入及切換班級後會保留。
學生可以在老師電腦前選擇喜歡的模樣。

其他動物在原本錨點附近左右活動；兔子的位移配合跳動節奏，牛緩步行走，企鵝與鵝加分時拍翅。
青蛙以起跳、騰空、落地的動作移動，落地時稍作停頓。
登記觸發打瞌睡時，這些動物會停止移動並顯示 `z` 提示。

### 光影與生氣

小鎮有左上方照進來的陽光：樹與道具的影子往右下倒（靠近根部濃、越遠越淡），
東西貼地的地方有一圈接地陰影，樹蔭裡有葉縫漏下來的光點；地面有暖色光斑與淡淡的光束，
還有蝴蝶、落葉、浮塵、飄過的雲影與飛鳥影子。一陣一陣的風由左往右吹過，草叢和樹梢會跟著擺。
陰影只落在地面上，不會讓任何一隻貓變暗。

這些都可以在 `js/config.js` 的「光影與生氣」調整：投影看起來偏灰就把 `LIGHT_STRENGTH` 調低；
只要光影、不要會動的小東西就把 `SCENE_LIFE` 改成 `false`；學校電腦跑不動就把 `AMBIENCE` 改成 `false`。

### 天氣

有晴天、多雲、下雨三種天氣。預設是「自動」：大部分時間晴天，偶爾轉陰、下一場雨，
換天氣時會花十幾秒慢慢轉過去。陰天影子變淡；下雨時路面變濕變暗、積出水窪、溪面冒漣漪，
蝴蝶和飛鳥會躲起來，雨停後地面慢慢變乾。變暗的只有地面，貓不會變暗。

工具列的天氣按鈕（🌤️）可以直接切換：自動 → 晴天 → 多雲 → 下雨 → 自動。
選過之後這台電腦會記住；想改預設值就改 `js/config.js` 的 `WEATHER`。

### 草地與小路

草地與小路是程式一個像素一個像素畫出來的：草色有深有淺，散著草葉、苜蓿、小花與會隨風擺的草叢；
小路是踩實的泥土，有碎石、踏腳石，偶爾還有一串貓腳印，路緣是不規則的，草會長進路面一點點。
地圖編輯器的地面筆刷照舊：「草叢地」草叢多、「花草地」花多，「石板(密)」是路心、
「石板(中)」是路緣、「石板(疏)」是草地裡的一塊踏腳石。路的邊界會自動接成平滑的曲線，不用一格一格對齊。
「石地板」仍然使用原本的素材圖塊。

### 小溪與橋

預設地圖下方有一條小溪，支線道路跨過的地方架了一座木橋。動物不會走進水裡，但可以走過橋。
用地圖編輯器（工具列的 ✎）也能自己挖水塘、畫河道：選「地面」裡的「水」塗成一片，
岸邊、深淺與水紋會依形狀自動畫好；再從「橋」挑南北向或東西向的橋擺在水上，蓋住的水面就能通行。
水與橋都是程式畫的，不需要額外素材。

### 畫面大小

小鎮會鋪滿整個視窗，不留邊。地圖放到視窗塞得下的最大尺寸，視窗比例跟地圖不一樣時，
多出來的邊緣補上延伸出去的草地與樹林，碰到地圖邊緣的路和溪也會一路接到畫面外。
這圈郊外只是背景：貓走不過去、編輯器改不到（編輯時地圖範圍會用虛線框起來），也不會存進地圖檔。

- 不管視窗多大、瀏覽器放大到幾 %，整張地圖都完整在畫面內，地圖四周也會留空間給名字，
  最靠邊的貓名字不會被切掉。瀏覽器放大（Ctrl +）時名字會跟著變大。
- 點右邊的貓時，角色面板會改從左邊滑出，不會蓋住那隻貓。
- 地圖不是剛好整數倍時，像素邊緣會稍微柔一點。想要每個像素都銳利，把 `js/config.js` 的
  `PIXEL_PERFECT` 改成 `true`：地圖只用 1 倍、2 倍這樣的整數倍放大，可能比較小，多的地方由郊外補滿。

### 啟動與瀏覽器限制

- 執行 `啟動.bat` 會啟動一個小型的本機網頁伺服器，並自動開啟瀏覽器。預設會使用 8173 連接埠，如果被其他程式佔用，它會自動往上尋找可用的埠（最高到 8200）。
- **必須使用 Chrome 或 Edge。** 這個工具需要寫入檔案，而寫入功能（File System Access API）在 Firefox 與 Safari 中不存在。如果偵測到不支援的瀏覽器，畫面會直接提示你。
- 若要關閉系統，只需關閉一開始彈出的黑色命令列視窗即可。

### 連接資料夾的機制

這通常是大家最容易卡住的步驟。基於瀏覽器的安全規則，網頁絕對不能任意觸碰你的硬碟，除非你親自「遞」一個資料夾給它。這是一項嚴格的瀏覽器限制，而不是設計上的選擇。

- 在你選擇 `data` 資料夾並授權之前，系統是唯讀的：貓咪會動，但任何分數都不會儲存。
- 這個授權會被瀏覽器記住。在之後的課堂中，你通常只需要再點擊一次確認即可。
- 連接成功後，工具列上的「連接資料夾」會換成**班級下拉選單**，旁邊的小圓燈亮綠色代表可以正常存檔。

### 帶多個班級

程式會自動掃描 `data` 資料夾裡所有的 `.json` 檔（`class-data.example.json` 不算），每一個檔案就是一個班級，全部列在工具列的下拉選單裡。上課前從選單挑那一班就好，切換時會自動把還沒寫完的分數先存起來。

要新增一個班級，就在 `data` 資料夾裡放一個新的 `.json`（用 `tools/import_roster.py --class-id 新班級代碼` 產生最省事），重新整理網頁就會出現在選單裡。

### 分數與等級的換算

- 每位學生一學期的滿分是 30 分，每得 3 分會升 1 級，最高 10 級。
- 這個「等級」數字，就是學期末你可以直接填入平時成績的加分（例如：7 級代表加 7 分）。
- 當學生達到 30 分滿分時，面板上的按鈕會變成灰色，並停止記錄新的分數。
- 請注意，檔案中永遠只會儲存「分數」，等級都是由程式即時推算出來的，不會另外儲存。

### 每一級都看得到的獎勵

每升一級，角色身邊就多一樣東西，而且會一直留著、一直動，不是升級那一下就沒了。貓咪和其他動物都一樣。

| 等級 | 解鎖 |
| --- | --- |
| Lv 1 | 家門口冒出小芽（貓咪也從坐著改成站著） |
| Lv 2 | 偶爾冒出愛心（開始會走動） |
| Lv 3 | 小芽開花（貓咪會用後腳站起來；企鵝、鵝會拍翅，兔子、青蛙會原地跳） |
| Lv 4 | 愛心和音符冒得更勤 |
| Lv 5 | 家門口長出向日葵 |
| Lv 6 | 身邊閃爍的星星 |
| Lv 7 | 蝴蝶相伴 |
| Lv 8 | 第二隻蝴蝶 |
| Lv 9 | 金色星星 |
| Lv 10 | 環繞的金色光點 |

點開角色，面板會寫出「下一級解鎖什麼」，讓學生知道再拿幾分會多出什麼。解鎖順序寫在 `js/config.js` 下半部的 `LEVEL_FX`。

角色正下方刻意什麼都不畫，留給影子；花園長在兩側。

進度條一分一格（升一級要 3 分就是 3 格），每加一分就亮一格。

**金色光環**給的是「目前全班分數最高」的學生：身後一圈慢慢轉的光芒，名字變金色。同分的人一起有，全班都還是 0 分時誰都沒有。不想要這種比較，把 `TOP_HALO` 改成 `false`。

**今日之星**給的是「這節課加分最多」的學生：頭上一顆會飄、會閃的星星，面板上也會寫「這節課 +2 分 ★ 今日之星」。只算這次打開網頁之後加的分，重新整理或重開網頁就從頭算，所以每節課每個人都有機會。復原會扣回去，登記不影響。不想要就把 `TODAY_STAR` 改成 `false`。

**全班共同目標**在工具列右邊：全班的分數加起來越多，長條就越滿。長條上的圓圈（新芽、花圃、噴泉、彩虹、煙火）還沒達到時是灰色，達到之後變彩色並輕輕發亮；滑鼠移上去看得到要全班累積幾分。門檻是全班滿分（人數 × 30）的幾成，所以人多人少的班級難度一樣。圓圈的圖示、名稱、門檻都在 `config.js` 的 `CLASS_GOAL`，可以改成班上約好的獎勵；改成 `[]` 就不顯示。

### 登記（不扣分的佐證紀錄）

上課睡覺、吵鬧這類事情需要留證據，但這套系統從頭到尾就只有一個扣分途徑（復原加分），所以「登記」完全不動分數。

- 點開那隻貓，角色面板上 `＋1` 底下有一顆棕色的「**登記**」按鈕。按下去會在畫面中央跳出對話框，填入事由後按「確認」。
- 對話框裡可以直接點常用事由（趴睡、吵鬧…）一鍵填入，也可以自己打字。按 `Enter` 等同確認，按 `Esc` 或「取消」則什麼都不會留下。
- 確認後，那筆事由會出現在面板下方的紀錄裡，標示「登記」與時間。**分數完全不變。**
- 登記錯人或事由打錯，可以按該筆紀錄旁的「撤銷」。跟復原一樣是追加一筆撤銷紀錄，原紀錄永遠留在檔案裡。
- 尚未連接資料夾時登記按鈕會變灰（寫不進檔案）；但即使學生已經滿分，仍然可以登記 —— 登記記的是事實，跟他拿幾分無關。

**貓咪打瞌睡**：當某位學生的「登記次數」超過「加分次數」時，他的貓會躺下來睡覺，而且不再走動。多加一次分就會立刻醒來。

這個表現只由老師實際登記的次數觸發，**不會因為分數低就自己發生** —— 沒有被登記過的學生，就算 0 分也是精神地坐著理毛。不想要這個效果的話，把 `js/config.js` 的 `DROWSY_ENABLED` 改成 `false` 即可。

### 復原操作 (Undo)

上課節奏很快，按錯是難免的，系統為此準備了完整的復原機制：

- 復原只在角色面板裡操作：點開那隻貓，面板下方每一筆紀錄旁邊都有「復原」按鈕。面板開著時也可以按 `Ctrl+Z` 復原最後一次加分。
- 復原的運作方式是「在歷史紀錄中加上一筆退回的紀錄，並將原本那筆標記為撤銷」。**系統永遠不會從紀錄中刪除任何東西**。當學生對分數有疑慮時，這些紀錄是你唯一的依據。
- 復原後，畫面會短暫出現訊息，並提供「取消復原」的選項讓你反悔。
- 復原功能跨越課堂依然有效。即使是昨天的操作失誤，今天依然可以復原。
- 這是系統內**唯一**可以扣除分數的方式，這是刻意設計的。

### 存檔與備份

- 加分後，系統會等待約 1 秒鐘再寫入檔案，因此連續快速加分只會觸發一次存檔。
- 每天第一次存檔時，系統會把**寫入之前**的檔案內容複製一份到 `data/backups/`，保留最近 30 份（份數由 `CONFIG.BACKUP_KEEP_DAYS` 決定）。備份的是舊內容而不是新內容，這樣今天誤操作才救得回昨天的狀態。
- **資料保護**：如果 `class-data.json` 檔案被改壞、無法順利解析，系統會顯示紅色橫幅，並拒絕寫入任何資料。這樣可以避免覆蓋掉原本的檔案而造成資料永久損壞。請在文字編輯器中修正該檔案後，點擊工具列的 ↻ 按鈕。

## 自訂設定 (config.js)

你可以用文字編輯器打開 `js/config.js`，修改裡面的設定。只要是合法的修改，存檔後重新整理網頁就會生效。幾個較常變動的項目包含：

- `TITLE`：顯示在畫面上方的文字。
- `CLASS_ID`：預設先開哪一個班級。連上資料夾後可以直接用工具列的下拉選單切換，通常不需要改這裡。
- `PLACEHOLDER_STUDENT_COUNT`：無名單時的佔位學生人數。
- `XP_MAX`、`XP_PER_LEVEL`、`MAX_LEVEL`：調整滿分與升級的門檻。
- `AWARD_VALUES`：設定加分按鈕的數值（若需要多種加分按鈕可以新增）。
- `NOTE_ENABLED`：是否顯示「登記」按鈕。
- `NOTE_PRESETS`：登記對話框裡的常用事由快捷鈕，改成自己班上的狀況會更順手。
- `NOTE_MAX_LEN`：登記事由的字數上限。
- `DROWSY_ENABLED`：登記次數超過加分次數時，貓咪是否會打瞌睡。
- `LEVEL_TITLES`：每個等級的稱號名稱。
- `SHOW_XP_NUMBERS`：是否在進度條旁顯示確切的分數。
- `TOP_HALO`：是否讓全班最高分的學生有金色光環。
- `TODAY_STAR`：是否讓這節課加分最多的學生頭上有星星。
- `CLASS_GOAL`：工具列上全班共同目標的圓圈（圖示、名稱、門檻）。
- `MAP_COLS`、`MAP_ROWS`：地圖的寬與高。地圖越大，放到視窗裡就越小，貓也跟著變小（名字大小不受影響）。改完可以在瀏覽器主控台看 `S.scale`，那是地圖 1 像素放大成螢幕幾個像素。
- `PIXEL_PERFECT`：`true` 時地圖只用整數倍放大，像素最銳利；預設 `false` 是放到塞得下的最大尺寸。
- `MAP_SEED`：改變此數字可重新隨機生成一張全新的地圖。
- `MIN_SPACING`：貓咪之間的最小間隔。
- `WANDER_RADIUS`：貓咪在原地的活動範圍。
- `BACKUP_KEEP_DAYS`：自動備份保留天數。

## 命令列工具

專案內的 `tools/` 資料夾提供了一些指令工具（需在命令列執行）：

- `python tools/import_roster.py`：將純文字名單轉為 JSON 資料檔（參見 `AGENT-名單匯入.md`）。
- `python tools/export_grades.py`：匯出 `data/export-YYYY-MM-DD.csv` 供期末結算成績。
- `node tools/test-model.js`：測試分數與等級計算邏輯是否正常。
- `tools/spritesheet-viewer.html`：用於在瀏覽器中重新確認角色素材的格線座標（若日後更換圖片素材會用到）。

## 刻意省略的功能

為了符合真實的教室情境，這套系統刻意排除了以下功能，並非遺漏：

- **沒有排行榜或排名機制**。唯一的比較是全班最高分的金色光環與這節課的今日之星，可以用 `TOP_HALO`、`TODAY_STAR` 關掉。
- **除了復原之外，沒有減分功能**。「登記」是留紀錄，不是扣分。
- **沒有死亡、昏倒或出局的視覺表現**。貓咪的姿勢只反映正向的差異：等級低的貓是坐著理毛，每升一級身邊就多一樣花、愛心、光圈之類的特效。**分數高低永遠不會讓貓看起來沒精神** —— 睡覺姿勢只由老師實際按下的「登記」觸發，是老師的操作結果，不是程式對分數的評價。
- **進度條絕對不使用紅色**。
- **沒有任何音效**。
- **沒有學生登入介面，也沒有網路連線**。分數只存在於你這台電腦的檔案裡。

## 疑難排解

| 狀況 | 說明與解決方法 |
| :--- | :--- |
| **雙擊 `啟動.bat` 卻一閃而過，無法開啟** | 電腦可能未安裝 Python。請至 Python 官網下載安裝，安裝時務必勾選「Add Python to PATH」選項，重新開機後再試。 |
| **點擊「連接資料夾」毫無反應** | 現在不會再毫無反應了 —— 一定會跳出訊息說明原因，請照著上面寫的做。若訊息說「被取消，或是根本沒有開起來」，先看一下工作列，選擇視窗有可能開在 Chrome 後面或另一個螢幕。啟動時的黑色視窗會顯示「瀏覽器：chrome.exe」或「msedge.exe」，可以確認用的是哪一個。 |
| **貓咪頭上只顯示數字，沒有姓名** | 這是還沒匯入真實名單時的正常狀態，顯示的是座號。匯入名單後就會顯示「座號. 姓名」（例如「1. 王大明」）。 |
| **畫面上方出現紅色橫幅警告檔案損毀** | 系統發現你的 `class-data.json` 檔案格式有誤（通常是因為手動編輯時漏了括號或逗號）。系統已切換為唯讀以保護資料。請用文字編輯器將檔案修復，再點擊工具列的 ↻ 按鈕。 |
| **手動編輯 JSON 後，分數看起來不對勁** | 系統的歷史紀錄與總分是連動的，手動編輯如果沒有同步處理可能會出現異常。強烈建議不要手動去改檔案裡的數字，請使用介面上的復原功能，或是透過 `tools/import_roster.py` 來維護名單。 |
